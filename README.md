# 🍳 CookSmart

CookSmart is a smart recipe and meal planning mobile application built using React Native.  
It helps users discover recipes, manage ingredients, and cook efficiently.

---

## 🚀 Features

- 🔍 Search recipes
- 📋 Ingredient management
- ❤️ Save favorite recipes
- 📱 Clean and simple mobile UI
- ⚡ Fast and responsive performance

---

## 🛠 Tech Stack

- React Native
- Expo
- JavaScript
- Node.js (if backend used)

---

## 📂 Project Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/cooksmart.git
cd cooksmart
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Start the app

```bash
npx expo start
```

Run on:
- Android Emulator (press `a`)
- Real device using Expo Go app
